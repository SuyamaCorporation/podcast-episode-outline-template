# Podcast Episode Outline & Show Notes Template

Fill in your episode title, intro hook, guest details, multiple labeled segments with talking points and target durations, a call to action, and resource links; the app instantly generates a formatted show notes document with live word-count guidance per section. You can export the output as a Markdown file or plain text, and save your draft to localStorage for later editing. The segment builder supports dynamic add/remove of sections to match any episode structure.
